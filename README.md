# Wakil Ahmed Marketplace – seller portal

Node.js + PostgreSQL backend for sellers, commissions, earnings and payouts.

## What it does
- Sellers and Vendors apply at `/register` by choosing an account type; both applications enter the existing admin review queue at `/admin/sellers`.
- Admin sets each seller's commission rate.
- Shopify sends `orders/paid` and `refunds/create` webhooks to `/webhooks/shopify`.
  Items are matched to sellers by the product **Vendor** field, which must equal the seller's shop name.
- Sellers see balance, orders and payment history. Admin records payouts at `/admin/payouts`.

## Environment variables (set these on Render, never in GitHub)
| Name | Value |
|---|---|
| `DATABASE_URL` | Internal Database URL from your Render Postgres page |
| `SESSION_SECRET` | Any long random string (40+ characters) |
| `ADMIN_EMAIL` | Your admin login email |
| `ADMIN_PASSWORD` | Your admin password (10+ characters) |
| `SHOPIFY_WEBHOOK_SECRET` | Client secret of your Shopify app, used for webhook verification |\n| `SHOPIFY_STORE_DOMAIN` | `wakilahmedllc.myshopify.com` (use your current `.myshopify.com` store domain) |\n| `SHOPIFY_ADMIN_ACCESS_TOKEN` | Admin API access token from a Shopify custom app with product, publication, inventory and location permissions |\n| `SHOPIFY_API_VERSION` | Optional; defaults to `2026-10` |
| `NODE_ENV` | `production` |
| `BRAND_NAME` | Optional, shown in the header |

Build command: `npm install`  Start command: `npm start`

## Shopify webhooks
Shopify admin → Settings → Notifications → Webhooks. Add two, format JSON:
- Order payment → `https://YOUR-SERVICE.onrender.com/webhooks/shopify`
- Refund create → same URL
Webhooks created there are signed with your store's webhook signing secret; use that
value for `SHOPIFY_WEBHOOK_SECRET` (shown at the top of the same Webhooks page).

## Seller product submissions
Approved sellers can submit product details from `/seller/products/new`. Submissions are isolated by seller account and enter the admin review queue at `/admin/products`. Admins can approve or reject submissions and leave feedback. Approval is recorded in the portal only; creating Shopify draft products and publishing them requires a separately configured Shopify Admin API app with appropriate product permissions. The existing Shopify webhook secret is not an Admin API access token.

## Seller TikTok Ads connection

The seller portal includes a seller-scoped TikTok Ads authorization page at
`/seller/advertising/tiktok`. Each approved seller authorizes their own
TikTok for Business advertiser account. Access tokens are encrypted with
AES-256-GCM and stored against that seller's user ID.

Configure these Render environment variables before enabling the connection:

| Name | Value |
|---|---|
| `TIKTOK_APP_ID` | App ID from TikTok for Business Developers > My Apps |
| `TIKTOK_APP_SECRET` | App secret from the same developer app |
| `TIKTOK_ADVERTISER_AUTH_URL` | Advertiser authorization URL generated by the approved TikTok developer app |
| `TIKTOK_TOKEN_ENCRYPTION_KEY` | 32 random bytes encoded as 64 hexadecimal characters |

Set the TikTok developer app's advertiser redirect URL to:

`https://seller.wakilahmed.com/seller/advertising/tiktok/callback`

TikTok must approve the developer app and requested Marketing API permissions
before sellers can authorize accounts. Keep app secrets and encryption keys
in Render environment settings, never in source control.

This milestone connects and disconnects advertiser accounts and displays
the advertiser IDs authorized by TikTok. Campaign reporting and campaign
management are separate follow-on features.


## Approved seller and vendor product publishing

When an admin approves an individual seller or business vendor listing, the portal creates the product in Shopify, applies the seller's shop name as the Shopify Vendor, sets the submitted price and SKU, tracks inventory at the first active Shopify location, and publishes to the Online Store sales channel. The product is tagged with its account type and portal submission ID. If publishing fails after product creation, the Shopify product ID is retained so the admin can retry without creating a duplicate. A direct HTTPS image URL ending in JPG, PNG, WebP or GIF is attached; social share links are intentionally not imported as product images. The existing Shopify webhook secret is not an Admin API access token.

Before enabling this feature, create a Shopify custom app and grant the Admin API scopes `write_products`, `read_publications`, `write_publications`, `write_inventory`, and `read_locations`. Install the app and add its Admin API access token to Render as `SHOPIFY_ADMIN_ACCESS_TOKEN`, with `SHOPIFY_STORE_DOMAIN` set to `wakilahmed.com`. Never commit the access token to GitHub or paste it into chat. The Online Store sales channel must be available in Shopify.
